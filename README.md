# PuntoCockpitSimulator
Simulates theering wheel and instrument cluster

## What does work now
This script opens a browser site where with html, css, js a 
drawn version of the fiat punto dashboard is visible. 

### Pressing buttons
Pressing buttons on the steering wheel wil send the b&m can 
message that is set to that key.

### Display screen
When also running PuntConnect the screen wil simulate the 
messages like the real car
